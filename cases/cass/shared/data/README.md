# shared/data/

This directory contains **symlinks only** — no actual data files live here.
All data resides on scratch at `/pscratch/sd/m/mpowell/CASS_LES/shared_data/`
to preserve home quota.

Run `shared/setup_shared_data.sh` to (re-)create the scratch files and symlinks.

## Files

| File | Scratch source | Notes |
|------|---------------|-------|
| `van_genuchten_parameters.nc` | copied from `microhh/misc/` | Soil type lookup table for LSM |
| `cass_snd.txt` | downloaded from NERSC portal | ARM SGP composite sounding (initial profiles) |
| `cass_sfc.txt` | downloaded from NERSC portal | Surface flux time series |
| `cass_lsf.txt` | downloaded from NERSC portal | Large-scale forcing profiles |
| `cass_ls2d_input.nc` | generated by `shared/preprocessing/cass_ls2d_input.py` | ERA5 composite radiation + soil profiles |
| `cass_cams_composite.nc` | generated by `shared/preprocessing/compute_cams_composite.py` | CAMS composite aerosol profiles on native model levels |

## To repair broken symlinks

```bash
cd cases/cass/shared/
bash setup_shared_data.sh
```
